# AGENTS.md

## Scope
This file applies to the `docs/` directory and its subdirectories.

## Documentation Guidelines
* Consult `docs/lang/spec/index.md` and the relevant feature articles when updating documentation or introducing new language features.
* Keep the language specification and grammar in sync with any documentation changes.

## Introductory website content

* In the homepage, short introduction, and language tour, use recognizable .NET
  tasks as context and focus explanations on the value of Raven's choices.
* Assume familiar programming constructs for experienced readers. Demonstrate
  classes, collections, and async APIs without reteaching their basics.
* Explain Raven-specific semantics where familiar syntax could mislead. Do not
  claim a feature is unique merely because its spelling differs from C#.
* Prefer complete examples with a visible outcome. Verify new Raven examples
  against the compiler before presenting them as runnable.
* Keep the beginner guide explanatory and the language reference comprehensive;
  the introductory editorial focus does not limit their coverage.
